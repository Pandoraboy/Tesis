# ADR-004 · Base de tesis acelerada

Estado: base documental adaptada a archivos adjuntos; propuestas de detalle pendientes de revisión.

Android, PostgreSQL y mensajes destacados sustituyen la base anterior Android/iOS, MySQL, anuncios y créditos. Se mantiene API primero. No se inicializa software en esta entrega.

Propuestas: siete entidades; user/admin; un destacado por mensaje; activación administrativa; consulta temporal sin cron como condición de corrección; foros sin plaza obligatoria; paginación inicial por página; administración mínima Android.

Consecuencia: reducir dependencias para conseguir un piloto defendible. Se documenta el cambio y se conserva la base histórica. No se afirma que pagos reales, recuperación por teléfono o evaluación de usuarios estén realizados.
