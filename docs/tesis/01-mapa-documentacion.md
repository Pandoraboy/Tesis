# Software y tesis

| Parte académica | Fuente del workspace | Evidencia todavía necesaria |
|---|---|---|
| Problema y contexto local | Visión y especificación original | Fuentes y levantamiento con actores |
| Objetivos y alcance | Requisitos | Confirmación con guía académica |
| Análisis de requisitos | RF/RNF, actores y procesos | Validación de requisitos |
| Diseño | Arquitectura, ADR y modelo | DER aprobado, decisiones y prototipos |
| Implementación | Commits por entrega | Código y ejecución |
| Pruebas | Plantilla de evidencia | Resultados reales por caso |
| Evaluación | Piloto E7 | Instrumento, participantes y análisis |
| Conclusiones | Resultados y limitaciones | Hallazgos derivados de evidencia |

LaTeX será el formato técnico indicado por los avances, pero no se presupone una plantilla institucional. Los estándares IEEE citados en el original se conservan como antecedentes; confirmar cuáles exige la universidad antes de afirmar cumplimiento. No hay levantamiento, revisión bibliográfica ni piloto realizados en este entregable.
