# Módulos MVP

| Módulo | Entidades | Responsabilidad |
|---|---|---|
| Identidad | users | Sesión, contacto y rol |
| Información local | categorias_lugar, lugares, horarios_lugar | Directorio, horarios y mapa |
| Comunidad | foros, mensajes | Lectura, publicación y moderación |
| Destacados | mensajes_destacados | Solicitud, aprobación y vigencia |
| Administración | Entidades anteriores | Operaciones protegidas, sin duplicar dominio |

Pagos, créditos, eventos y roles múltiples no forman módulos implementables en esta base.
