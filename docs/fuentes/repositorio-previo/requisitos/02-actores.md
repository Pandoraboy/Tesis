# Actores del sistema

## Visitante

Puede:

- Consultar lugares.
- Usar el mapa.
- Revisar horarios.
- Ver eventos.
- Leer chats.
- Ver anuncios.
- Registrarse.
- Iniciar sesión.

## Usuario registrado

Puede:

- Realizar todas las acciones públicas.
- Escribir mensajes.
- Reportar contenido.
- Crear anuncios.
- Comprar créditos.
- Consultar su saldo.
- Revisar su historial.

## Moderador

Puede:

- Revisar reportes.
- Ocultar mensajes.
- Suspender temporalmente usuarios.
- Revisar anuncios.
- Aprobar o rechazar publicaciones.

## Administrador

Puede:

- Gestionar usuarios.
- Gestionar roles.
- Gestionar categorías.
- Gestionar lugares.
- Gestionar horarios.
- Gestionar plazas.
- Gestionar eventos.
- Gestionar anuncios.
- Gestionar reglas de créditos.
