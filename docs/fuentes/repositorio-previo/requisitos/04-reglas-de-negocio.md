# Reglas de negocio

## Acceso

- Un visitante puede consultar información pública.
- Solo un usuario autenticado puede escribir mensajes.
- Solo un usuario autenticado puede crear anuncios.
- Las funciones administrativas requieren permisos específicos.

## Lugares

- Todo lugar debe pertenecer a una categoría.
- Todo lugar debe tener coordenadas válidas.
- Los lugares inactivos no se muestran públicamente.
- Los horarios especiales tienen prioridad sobre los horarios normales.

## Chats

- Cada plaza tiene una sala de chat.
- Los cuatro chats son públicos para lectura.
- La ubicación del usuario no limita el acceso a las salas.
- Los mensajes deben tener una longitud máxima definida.
- Los usuarios pueden ser limitados por frecuencia de publicación.
- Los mensajes pueden ser reportados.

## Anuncios

- Todo anuncio debe pertenecer a un usuario.
- Todo anuncio debe pasar por revisión.
- Los créditos se reservan antes de la aprobación.
- Un anuncio rechazado devuelve los créditos reservados.
- Un anuncio aprobado consume los créditos.
- Todo anuncio debe tener fecha de inicio y término.

## Créditos

- Los créditos se obtienen mediante compras verificadas.
- Cada movimiento debe quedar registrado.
- El saldo no puede quedar negativo.
- Una compra no puede acreditarse dos veces.
- Los créditos deben mantenerse asociados a la cuenta del usuario.
