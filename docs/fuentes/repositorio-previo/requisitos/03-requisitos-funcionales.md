# Requisitos funcionales

| Código | Requisito |
|---|---|
| RF-01 | El visitante podrá consultar lugares sin iniciar sesión. |
| RF-02 | La aplicación podrá solicitar la ubicación del dispositivo. |
| RF-03 | La aplicación mostrará lugares cercanos. |
| RF-04 | La aplicación mostrará la farmacia abierta más cercana. |
| RF-05 | La aplicación mostrará el cajero disponible más cercano. |
| RF-06 | El usuario podrá filtrar lugares por categoría. |
| RF-07 | El usuario podrá revisar actividades del día. |
| RF-08 | El visitante podrá leer los chats territoriales. |
| RF-09 | El usuario registrado podrá escribir mensajes. |
| RF-10 | El usuario podrá reportar mensajes. |
| RF-11 | El usuario podrá crear anuncios. |
| RF-12 | El usuario podrá comprar créditos. |
| RF-13 | El sistema registrará cada movimiento de créditos. |
| RF-14 | El moderador podrá aprobar o rechazar anuncios. |
| RF-15 | El administrador podrá gestionar lugares y categorías. |
| RF-16 | El sistema tendrá cuatro chats vinculados a plazas. |
