# Primeros commits sugeridos

```bash
git add .
git commit -m "docs: crea estructura inicial del proyecto"
```

Después del modelo conceptual:

```bash
git commit -m "docs: agrega actores y procesos del sistema"
git commit -m "docs: agrega modelo entidad relacion"
git commit -m "docs: agrega modelo relacional"
```

Cuando se inicialice Laravel:

```bash
git commit -m "chore: inicializa proyecto Laravel"
git commit -m "feat: crea modulo de categorias"
```

Cuando se inicialice Flutter:

```bash
git commit -m "chore: inicializa proyecto Flutter"
git commit -m "feat: crea pantalla inicial"
```
